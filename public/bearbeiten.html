Hochgeladene Bilder ersetzen die Unsplash-Platzhalter auf diesem einen Entwurf – alle anderen Entwürfe bleiben unberührt. Sie werden im Browser auf 1800 px Breite verkleinert und als JPEG gespeichert. Die veröffentlichte Fassung ändert sich dadurch noch nicht, dafür braucht es weiterhin npm run pages bzw. npm run publish-site.

✏️ Texte per Prompt anpassen

Beschreiben Sie in eigenen Worten, was sich ändern soll (z. B. "Schlagzeile persönlicher formulieren" oder "Beschreibung vom Schweinsbraten appetitlicher schreiben"). Das Sprachmodell schlägt nur Headline, Schlagzeile und einzelne Gerichtsbeschreibungen vor – nie Bilder, Preise oder Struktur der Seite. Nichts wird live geschaltet, bevor Sie die Vorschau unten ausdrücklich übernehmen.
